# My School Color Point

Tampermonkey-скрипт для окрашивания оценок в электронном журнале "Моя Школа" (authedu.mosreg.ru).

## 📁 Структура проекта

```
myschool-color-point/
├── build.sh                           # Скрипт сборки (генерирует версию)
├── dist/
│   └── myschool-color-point.user.js   # Готовый скрипт для Tampermonkey
└── src/
    ├── config.js      # Константы, цвета, настройки по умолчанию
    ├── coloring.js    # Логика окрашивания, расчёты, утилиты
    ├── ui.js          # Стили, кнопки, модальное окно настроек
    └── main.user.js   # Точка входа, мониторинг URL
```

## 🔧 Сборка

```bash
cd myschool-color-point
bash build.sh
```

Результат: `dist/myschool-color-point.user.js`

Версия генерируется автоматически в формате `YYYY-MM-DD_HH-MM-SS`.

## 📋 Основные функции

### main.user.js — Точка входа

| Функция | Описание |
|---------|----------|
| `main()` | Точка входа, запускает мониторинг URL |
| `isTargetUrl(url)` | Проверяет соответствие URL странице журнала |
| `initOnJournalPage()` | Инициализирует скрипт на странице журнала |
| `initUrlMonitor()` | Мониторит изменения URL для SPA-навигации |

### coloring.js — Логика окрашивания

#### Состояние

| Объект/Переменная | Описание |
|-------------------|----------|
| `JournalState` | Глобальное состояние: тип округления, количество уроков, настройки |
| `tableObserver` | MutationObserver для отслеживания изменений в таблице |

#### Настройки

| Функция | Описание |
|---------|----------|
| `loadSettings()` | Загружает настройки из localStorage, объединяет с DEFAULT_SETTINGS |
| `saveSettings(settings)` | Сохраняет настройки в localStorage |
| `applyHideAverageMarkSetting()` | Применяет настройку скрытия среднего балла |
| `removeBannerAndSetHeight()` | Удаляет баннер госуслуг, устанавливает высоту `calc(100vh - 40px)` |
| `removeHeaderAndSetHeight()` | Удаляет шапку сайта, устанавливает высоту `calc(100vh)` |

#### Расчёт комбинаций

| Функция | Параметры | Возвращает |
|---------|-----------|------------|
| `findBestCombo(sum, count, targetGrade, isMathRound)` | Сумма оценок, количество, целевая оценка, тип округления | `{ label, isFormula, comboSize }` |
| `checkComboReachesThreshold(sum, count, comboGrades, threshold)` | Данные оценок и порог | `boolean` |
| `calcFivesNeeded(sum, count, threshold)` | Данные оценок и порог | `number` или `null` |

#### Окрашивание

| Функция | Описание |
|---------|----------|
| `colorizeTable(tableBody)` | Основная функция окрашивания таблицы |
| `colorizeStandardRow(row)` | Окрашивает обычную строку с оценками |
| `colorizeAverageCell(row, gradesData)` | Окрашивает ячейку среднего балла |
| `colorizeSummaryRow(row)` | Окрашивает строку с итоговыми оценками |
| `colorGradeCell(cell)` | Окрашивает ячейку с оценкой за урок |
| `colorFinalGradeCell(cell, allGrades, isWeNeed3Grades)` | Окрашивает итоговую оценку |
| `highlightControlForms()` | Подсвечивает запрещённые формы контроля в заголовке |

#### Tooltip

| Функция | Описание |
|---------|----------|
| `showTooltip(event)` | Показывает tooltip при наведении |
| `hideTooltip(event)` | Скрывает tooltip |
| `createGradeBadge(grade)` | Создаёт цветной badge для оценки |
| `formatTooltipContent(text)` | Форматирует текст tooltip с badge |

### ui.js — Интерфейс

| Функция | Описание |
|---------|----------|
| `createStyles()` | Создаёт все CSS-стили |
| `createButtons(parentElement)` | Создаёт кнопку настроек |
| `createSettingsIcon()` | Возвращает SVG иконку настроек (шестерёнка с кистью) |
| `insertButtons()` | Вставляет кнопку в заголовок журнала |
| `showModal()` | Показывает модальное окно настроек |
| `downloadAsFile()` | Скачивает таблицу как HTML |

## ⚙️ Настройки

Все настройки сохраняются в `localStorage` под ключом `MSCP`.

### Цветной режим для:

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `colorAccumulation` | `true` | Окрашивание прогресс-бара накопляемости |
| `colorLessonGrades` | `true` | Окрашивание ячеек с оценками за уроки |
| `colorAverageGrade` | `true` | Окрашивание ячеек среднего балла |
| `colorBorderlineGrades` | `true` | Уголок "почти достиг" у пограничных оценок |

### Дополнительно:

| Настройка | По умолчанию | Описание |
|-----------|--------------|----------|
| `hideAverageMark` | `true` | Скрывать средний балл при загрузке страницы |
| `hideBanner` | `false` | Удалять баннер госуслуг |

## 🧮 Алгоритм расчёта комбинаций

### Приоритет поиска:
1. **Одна оценка** (от меньшей к большей): `3` → `4` → `5`
2. **Две оценки** (от меньшей суммы): `3,3` → `3,4` → `4,4`/`3,5` → `4,5` → `5,5`
3. **Формула**: `[5] × N` — если комбинации не найдены

### Оптимизация отображения:
Если single-оценка содержится в double-комбинации, показываем только single.

**Пример**: Для достижения `4` подходят `4` и `3,5`. Поскольку `5` (из `3,5`) больше `4`, показываем только `4`.

### Пороги округления:

| Оценка | Математическое | Лицейское |
|--------|----------------|-----------|
| 5 | ≥ 4.5 | ≥ 4.65 |
| 4 | ≥ 3.5 | ≥ 3.6 |
| 3 | ≥ 2.5 | ≥ 2.6 |

**Лицейское округление** используется для предметов: Изобразительное искусство, Музыка, Труд, Физическая культура.

## 🔌 Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/)
2. Откройте `dist/myschool-color-point.user.js`
3. Скопируйте содержимое
4. В Tampermonkey создайте новый скрипт и вставьте код
5. Сохраните

## 📝 Разработка

### Добавление новых файлов:
1. Создайте файл в `src/`
2. Добавьте его в `build.sh` в нужном порядке

### Изменение цветов:
Отредактируйте `COLORS` в `src/config.js`

### Изменение порогов:
Отредактируйте `GRADE_THRESHOLDS` в `src/config.js`

### Изменение запрещённых форм контроля:
Отредактируйте `CONFIG.CONTROL_FORMS` в `src/config.js`
